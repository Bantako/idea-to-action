# idea-to-action

> **このプロジェクトは 2026-05-04 に開発を終了しました。**

## 何を作ろうとしていたか

曖昧なアイデアや「やりたいこと」を具体的な行動に落とし込む Android アプリ。

- Capture タブ: メモ投入（10秒で終わる）
- Projects タブ: プロジェクト管理・ステップ管理
- Today タブ: フォーカス中プロジェクトの次ステップ確認・完了記録

Memo / Step / Project / DailyLog の4エンティティで構成し、AI がプロジェクト候補を提案する設計。

## なぜたたんだか

**既存ツールの組み合わせで目的を達成できた。**

Todoist API + Claude Code を組み合わせることで、「やりたいことの管理」と「ローカルノートとの整合性維持」というフローが実現できた。独自アプリを開発・保守するより、すでに動いているツールを使うほうが実用的と判断した。

## 開発の経緯

- 当初は Node / Edge / Theme による DAG 設計で実装（Step 1〜8）
- モバイルで DAG が実際に使われないことが判明し、設計を見直し
- Memo / Step / Project / DailyLog へのシンプルな設計に移行中の段階で終了

技術スタックは Kotlin + Jetpack Compose + Room + Hilt。NixOS 上の CLI 中心ワークフローを前提とした開発環境。
